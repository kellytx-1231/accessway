AccessWay Malaysia demo — Vercel deployment

This is a static HTML site. The main page is index.html.

Deploy with Vercel:
1. Sign in to https://vercel.com/
2. Create a GitHub repository and upload index.html and vercel.json from this folder, OR use Vercel's supported CLI deployment flow.
3. In Vercel, import the repository and deploy. No build command is required; use the project root as the root directory.
4. Vercel will generate a public URL such as https://your-project-name.vercel.app.

Note: This package prepares the site for deployment but does not publish it to your Vercel account automatically.
